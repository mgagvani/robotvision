# Paper Figure Style Guide

This directory contains scripts and caches for paper figures. The current
reference figure is Fig. 3, generated by `plot_counterfactual_figure.py`.

## Figure 3 Layout

- Use a full-page-width multi-panel figure.
- Put the compact edit-distribution bar chart at the top.
- Use a 4-column layout for example rows:
  - Original image
  - Edited image
  - Normalized SAE feature change
  - Predicted trajectories
- Use three main rows for the paper figure:
  - Red light → Green light
  - Add stop sign
  - Add pedestrian
- Use real arrows (`→`) in labels, not `->`.
- Do not add explanatory text at the very top or bottom of the figure.
- Row-side labels should be semantic edit types, not dataset IDs.

## Typography

- Use an academic serif style for paper figures:
  - `font.family = serif`
  - preferred serif list: `STIXGeneral`, `Times New Roman`, `DejaVu Serif`
  - `mathtext.fontset = stix`
- Keep labels compact. Avoid oversized titles inside panels.
- Export PDFs with editable text:
  - `pdf.fonttype = 42`
  - `ps.fonttype = 42`

## Color And Styling

- Keep the palette restrained and readable:
  - Original trajectory: blue (`#2F6C9F`)
  - Edited trajectory: red (`#B94A48`)
  - SAE positive bars: blue (`#2F6C9F`)
  - SAE negative bars: orange (`#C45A2A`)
  - Gridlines: light gray (`#D8DCE2`)
- Avoid decorative gradients, orbs, and extra annotations.
- Use thin panel borders around camera images.
- Use light gridlines in quantitative panels.

## Image Panels

- Crop camera images slightly to remove distracting lower/upper margins:
  - top crop around 2%
  - bottom crop around 90%
- Preserve the scene context; do not zoom too aggressively.
- Overlay only a compact black translucent label in the lower-left:
  - `a. Red light → Green light`
  - `image-only edit`
- Keep original and edited images aligned in size.

## Edit Distribution Bar Chart

- Label the y-axis `% of frames`.
- Include the small distribution chart, not a large table.
- Use manifest-derived percentages over the 1000 candidate frames.
- Current labels include:
  - green → red
  - add pedestrian
  - red → green
  - add stop sign
  - yellow → green
  - remove stop sign

## SAE Feature Panel

- Title/label should be `Normalized SAE feature change`.
- Do not show `n=...` labels.
- Keep feature IDs inside the SAE panel so they do not spill into images.
- Use top features by absolute edit-direction mean normalized delta:
  - source: `sae_visual_gen_feature_summary_block_3.csv`
  - metric: `mean_delta_scale_units`
- Use signed horizontal bars centered at zero.

## Trajectory Panel

- Use real selected original and edited predicted trajectories when available.
- Source the real trajectory cache from:
  - `fig3_counterfactual_trajectories.json`
- Generate that cache with:
  - `extract_counterfactual_trajectories.py`
  - or the Slurm helper `scripts/run_fig3_trajectory_cache.slurm`
- Do not modify the large visual-gen `.pt` analysis caches just to make figures.
- The trajectory panel should show:
  - lateral `y` on x-axis
  - forward `x` on y-axis
  - original and edited selected proposals
  - ego origin marker

## Example Selection

- For the final paper figure, choose examples that are visually interpretable
  and whose trajectory change agrees with the edit semantics.
- For browsing candidates, use the gallery workflow:
  - `extract_counterfactual_trajectories.py --expected_forward_delta`
  - `plot_counterfactual_gallery.py`
  - `scripts/run_counterfactual_gallery.slurm`
- Expected final-forward-displacement signs:
  - red → green: positive
  - green → red: negative
  - add stop sign: negative
  - remove stop sign: positive
  - add pedestrian: negative
  - remove pedestrian: positive
- Exclude already-reviewed examples when regenerating galleries.
